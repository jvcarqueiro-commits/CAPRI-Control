# CAPRI Control

Aplicativo Android experimental da assistente CAPRI, com controle local autorizado via acessibilidade, comandos por texto e reconhecimento de voz.

O app não utiliza API externa nem capta a tela remotamente. Não é uma IA conversacional nesta fase.

## Instalação

Quando o build do GitHub Actions terminar, abra Actions > Build CAPRI APK > Artifacts, baixe o arquivo ZIP `CAPRI-Control-debug-apk` e instale `app-debug.apk` no Samsung.

Depois, habilite manualmente CAPRI em Configurações > Acessibilidade > Aplicativos instalados. Desative o serviço quando não estiver usando.

## Aviso

Código experimental não auditado e ainda não testado num telefone físico. Verifique a origem do APK antes de conceder acesso à interface.
